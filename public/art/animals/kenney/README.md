# Kenney Animal Pack Remastered

Selected transparent PNGs from **Animal Pack Remastered** by Kenney Vleugels.
The project-supplied pack includes a CC0 license; a normalized copy is kept in
`LICENSE.txt` beside the selected files.

Only four animals used in the Creation scene are included. Legacy SWF files,
URL shortcuts, thumbnails, metadata databases, duplicate styles, and unused
sprites remain outside the repository.
