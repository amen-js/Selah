# Kenney Nature Kit 2.1 subset

These GLBs are unmodified files extracted from the official Kenney Nature Kit
2.1 archive. `License.txt` is the original license notice shipped in that
archive.

- Source: https://kenney.nl/assets/nature-kit
- Archive: https://kenney.nl/media/pages/assets/nature-kit/37ac38a37b-1677698939/kenney_nature-kit.zip
- Archive SHA-256: `fa7974a0d342bfe63c38664ba9f8ec1a4aab8ea25f099bdc56870e33588c4d9d`
- Creator: Kenney
- License: CC0 1.0 Universal
- License URL: https://creativecommons.org/publicdomain/zero/1.0/

The files are split by source asset and do not bundle a whole world. All
textures are embedded as vertex colours/material factors in these exports, so
there are no sidecar texture paths to resolve. They contain no skeletons or
animation clips; no collision proxy is declared in the manifest.
