# Quaternius Universal Base Characters — selected pair

- Official page: https://quaternius.com/packs/universalbasecharacters.html
- Pack: official Standard/free archive.
- License: CC0 1.0 Universal; original `License.txt` retained here.
- Source models: `Superhero_Male_FullBody.gltf` and
  `Superhero_Female_FullBody.gltf`.
- Processing: packed as GLB, textures capped at 1024px, then encoded as WebP
  with glTF-Transform 4.4.2. Geometry and humanoid skins are retained.
- `adam.glb` SHA-256:
  `624475f7e4d5d410286cfe7007301380ddaa4d12d24b9ede63ab73dea2af0b7e`.
- `eve.glb` SHA-256:
  `e59f51bd141eb2d71a712fb3acd8e1869d235833dbdfbbcf6b356d84fd58b0ef`.

The free base models contain no animation clips. The Creation runtime lowers
their T-pose arms and applies a subtle, deterministic idle movement after
cloning each skeleton.
