## Runtime structure

- Every model is glTF Binary 2.0 generated by `UnityGLTF`.
- Geometry buffers are embedded; the palette image is the only external URI.
- Models are static and contain no skins or animation clips.
- All models use one material and one shared 512×512 indexed PNG texture.
- `workbench.glb` is the only multi-node asset: bench, paper, and hammer. All
  other GLBs contain one node, one mesh, and one primitive.
- These files are visual props. Gameplay collision should use authored simple
  Rapier colliders rather than mesh-derived colliders.

No ships, boats, characters, terrain, or unrelated pack content were imported.
