Only the GLB collections used by Selah are kept here. Each collection contains
multiple named meshes; map data selects one mesh at runtime instead of loading
the entire collection as a visible prop.

| File | Named meshes used by Selah |
| --- | --- |

| `rocks.glb` | `Rock_1` … `Rock_5` |

| `flower-bushes.glb` | `Plant_2`, `Plant_Flowers` |
